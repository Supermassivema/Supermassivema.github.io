# 새 작가 / 새 작품 올리기 (자료 투입 폴더)

이 폴더(`_incoming/`)는 **아직 사이트에 반영되지 않은 원본 자료를 임시로 올려두는 곳**입니다.
Jekyll 빌드에서 제외되므로 여기에 올린 파일은 사이트에 바로 노출되지 않습니다.

## 사용 방법 (3단계)

### 1) 작가 폴더 만들기
`_incoming/` 안에 **작가 이름으로 폴더**를 하나 만듭니다.
예: `_incoming/Kim Young Hee/`

### 2) 폴더에 자료 넣기
그 폴더 안에 아래 3가지를 넣습니다.

| 파일 | 설명 |
|------|------|
| `info.md` | `_incoming/_form.md` 를 복사해서 아는 만큼 채운 정보 파일 (필수) |
| `profile.jpg` | 작가 프로필 사진 (jpg/png/webp 무엇이든) |
| 작품 이미지들 | `work-01.jpg`, `work-02.jpg` … 순서대로 (이름 형식은 자유, 순서만 맞으면 됨) |

`info.md` 는 아는 정보만 채우면 됩니다. **모르는 항목은 비워둬도 됩니다.**
약력·경력은 형식 신경 쓰지 말고 있는 그대로(한글/영문 섞여도 OK) 붙여넣으면 됩니다.

### 3) 명령하기
채팅에 이렇게 말하면 됩니다:

> **"«작가이름» 작가 자료 반영해줘"** (또는 `/new-artist «작가이름»`)

그러면 자동으로:
- `info.md` 와 이미지들을 읽어 파악하고
- 프로필/작품 이미지를 `assets/images/work/«작가»/` 로 정리 + webp 생성
- `_artists/«slug».md` (작가 페이지) 와 `_artworks/«slug»-work-NNN.md` (작품들)를 **틀(`_templates/`)에 맞춰** 생성
- 빌드로 검증 후 결과를 보고합니다. (커밋/푸시는 확인 후 진행)

---
※ 반영이 끝난 뒤 `_incoming/«작가»/` 폴더는 지워도 되고, 백업으로 남겨둬도 됩니다.
